# 20260920更新：v2.12.0 

相比上一版 **v2.11.22 Release**，这次 **v2.12.0** 的更新重点可以概括为：**项目目录重构 + 校对流程强化 + 新旧词表比较 + 操作效率优化**。

### v2.12.0 相比 v2.11.22 的主要新增

* **全新的 Project Storage v2**
  * 软件生成的数据统一收纳到项目目录下的 `_PictureCapture/`
  * 项目根目录不再散落大量设置、OCR、PDIC、切图及缓存文件
  * 项目设置、PDIC/PPP、OCR 数据、切图、规则、导出结果等都有统一存储位置
  * 支持旧项目自动识别与安全迁移
  * 原始扫描图片、用户自己的 `wordslist.txt` 等不会被擅自移动
  * 为后续“项目直接复制给其他用户即可继续工作”打下基础
* **新增【新旧比较】功能**
  * 主界面在【词条校对】后增加【新旧比较】
  * 可按当前选定页面范围提取 PDIC 词条
  * 与指定 `wordslist.txt` 中对应页面内容进行比较
  * 自动识别：
    * 新增词条
    * 删除词条
    * 修改词条
  * 使用序列对齐，避免中间增加一条后导致后续全部误判
  * 可分别查看 PDIC 合集、旧词表片段和差异结果
  * 差异报告文件名自动包含页面范围，例如：
    `words_diff_0055-0070_...txt`
* **校对界面大幅增强**
  * 新增独立的 **单行高**
  * 新增 **单字行高**
  * 中文单字默认可按单行高约 **2.5 倍**处理
  * 新增“上下安全空间”控制
  * 对单字词头不再过度依赖相邻横线位置，解决画线略有偏差时切图过窄的问题
  * 校对界面可直接调整这些参数
* **校对翻页预加载**
  * 当前页加载完成后，后台预加载上一页和下一页
  * 同时准备图像、PDIC、PPP、OCR 和校对切图
  * 明显减少【上一页 / 下一页】时的等待时间
  * 缓存未完成时仍可自动回退到原有加载方式
* **校对词条与主界面联动**
  * 点击校对界面的某个文本框后
  * 主界面自动用**淡黄色单行高亮**显示对应词条位置
  * 切换词条时高亮同步移动
  * 关闭校对窗口后自动取消高亮
* **校对界面支持快速删除词条**
  * 每个文本框左侧新增 `[X]`
  * 支持和主界面一致的反引号 `` ` `` 快捷删除
  * 删除后同时移除：
    * 校对界面的词条切图
    * 校对文本框
    * 主界面对应文本框
    * 对应画线
  * 删除 OCR candidate 时会保存人工删除状态，防止重新加载后再次出现
* **主界面 OCR 显示可独立控制**
  * 校对期间可关闭主界面的：
    * OCR 内容选择
    * OCR 结果底色
  * 两项均提供独立开关
  * 关闭校对窗口后可恢复正常显示
  * 减少校对时主界面的视觉干扰
* **校对数据保存流程优化**
  * 翻页前会先提交当前校对内容
  * 避免主界面的旧文本再次覆盖刚刚修改的结果
  * 删除中间词条前也会先同步当前页编辑内容，减少行号变化造成的错位风险

# Picture Capture v2.11.12

Picture Capture 是一个面向扫描词典页面的桌面工具，用于词头定位、OCR 辅助画线、人工校对、PDIC/PPP 标注、批量词条填充、插图标注与切图，以及 PicDic 相关输出。

本发布包是 **v2.11.12 的干净公开发布版**。内部开发分析、历史验证文档、测试缓存、build 目录等均已移除；保留运行所需源码、Profile 资源、安装脚本、wheel 和用户说明。

> 建议先阅读本文件完成安装和基本工作流；所有参数的详细含义见 [`SETTINGS_REFERENCE.md`](SETTINGS_REFERENCE.md)；项目文件与输出格式见 [`FILE_FORMATS_AND_OUTPUTS.md`](FILE_FORMATS_AND_OUTPUTS.md)。

## 1. 运行环境

- Python **3.10 或更高版本**。
- 基础依赖：Pillow、NumPy。
- 可选 OCR：
  - PaddleOCR / PaddlePaddle：用于主要词头识别与版面检测。
  - Tesseract：用于对照 OCR、补漏和多 OCR 融合。Tesseract 是外部可执行程序，需要单独安装。
  - Google Lens：可作为第三意见；需要网络连接。
- 支持扫描图像：TIF/TIFF、PNG、JPG/JPEG、BMP。

### Windows 最简单启动方式

1. 解压整个 ZIP。
2. 双击 `run_windows.bat`。
3. 脚本会先安装基础 Python 依赖，再启动程序。
4. 如果需要 PaddleOCR，再双击 `install_paddleocr_windows.bat`。
5. 如果需要 Google Lens，可双击 `install_ocr_extras_windows.bat`。

### 命令行启动

```bash
python -m pip install -r requirements.txt
python run.py
```

或者安装随包 wheel：

```bash
python -m pip install dist/picture_capture_restored-2.11.12-py3-none-any.whl
picture-capture
```

## 2. 项目是什么

一个“项目”就是一个包含扫描页的目录。程序打开项目目录后，会把目录内支持的图片按文件名排序作为页面序列。

典型结构：

```text
MyDictionary/
├─ 0001.png
├─ 0002.png
├─ 0003.png
├─ 0001.pdic
├─ 0001.ppp
├─ wordslist.txt
├─ picture_capture_settings.json
├─ dictionary_profile.json
└─ QT/
   ├─ PaddleOCR/
   ├─ PWW/
   ├─ PIC/
   ├─ PicDic/
   └─ CropPlan/
```

`.pdic` 保存词条线与词头文字；`.ppp` 保存插图多边形。两者都与对应图片同名。

## 3. 推荐工作流

### 3.1 打开项目与版面校准

1. 点击 **打开项目目录**。
2. 在“页面范围”选择当前页、当前页至末页或指定范围。
3. 在“一、普通版面参数”先确认：分栏数、页眉 Y、单栏宽、栏间空、单行高、行间空。
4. 可点击 **检测版面** 自动估计分栏、页眉、栏宽等；自动结果建议目视确认。
5. 在 **更多参数 → Profile** 选择最接近当前词典的版面 Profile。

### 3.2 生成词头线

- **运行普通画线**：使用传统版面/左缘规则，不调用 OCR 识别词头文字。
- **运行OCR画线**：使用 PaddleOCR 为主的 OCR 词头检测，可与 Tesseract / Lens 对照融合。
- OCR 区的“①复用缓存”适合重复调参数；“②强制重新识别”会重新执行 OCR。

OCR 或普通画线会重写所选页面的 PDIC 画线，因此批量操作前应确认页面范围。

### 3.3 人工修正与校对

- 主图中可以人工增加、删除或调整词条线。
- 每个词条文本框可直接修改词头文字。
- 有 OCR 候选时，文本框旁会出现 `OCR ▾`，可直接采用 PaddleOCR、Tesseract、Lens 或融合结果。
- 点击 **词条校对** 打开专用校对窗口；右侧显示 OCR 候选与 wordslist 辅助词表。
- `wordslist.txt` 可达到十几万行；程序只在界面显示当前词附近的小窗口，不会一次性建立十几万个 GUI 项。

### 3.4 用分页词表批量填词

1. 点击 **选择词条文件**，选择有页码边界的 `_WordsOfPages.txt` 或兼容 TXT。
2. 设置主界面页面范围。
3. 点击 **填充既有词条**。

程序会按页把 TXT 中的词条依次填入已有横线，不会把一页多出的词溢出到下一页。

页面列表的“填充状态”含义：

- `一致`：PDIC 线数与 TXT 词数一致。
- `少 N`：PDIC 线数比 TXT 少 N。
- `多 N`：PDIC 线数比 TXT 多 N。
- `未核对`：尚未执行该页计数核对。
- `无资料`：所选 TXT 没有该页数据。
- `待重新核对`：核对后又增删了词条线。

仅修改词头文字不会使状态失效；增删横线会变为“待重新核对”。

### 3.5 插图 PPP

- **插图识别**：对所选范围自动检测插图，生成 PPP 多边形。再次识别只替换自动区域，不覆盖人工区域。
- **编辑插图**：进入 PPP 编辑模式。
  - 每个 PPP 有独立名称文本框。
  - 名称框显示在 PPP 区域外的右上方；靠近页面右侧时会自动避让。
  - 多边形可拖顶点。
  - 矩形 PPP 还可直接拖四条边的中点手柄。
  - 名称框旁 `×` 可删除单个 PPP。
- PPP 名称若与词头一致，切图计划会把该 PPP 视为与该词条关联。

### 3.6 切图

所有实际影响词条切图与插图切图的参数统一在 **切图设置** 中。

建议流程：

1. 设置页面范围。
2. 打开 **切图设置**，确认上下边界、左右留白、PPP 外扩、并行进程等。
3. 在主界面勾选 **切图预览（主图）**，直接查看最终 Crop Plan。
4. 预览无误后执行 **词条切图** 或 **插图切图**。

词条切图结果写入 `QT/PWW/`；插图切图结果写入 `QT/PIC/`。

如果勾选“是否综合插图计算切图信息”：

- 关联 PPP 完整位于词条切图内：随词条输出，不再单独切 PPP。
- 关联 PPP 与词条部分相交：词条矩形与 PPP 多边形联合后切图，不再单独切 PPP。
- 关联 PPP 完全在词条切图外：单独生成 `(P数字).png`。

如果关闭该选项：

- 词条只按自身矩形切图，不由 PPP 扩框或改变顺序。
- 完整位于词条内部的插图自然保留在词条图中，并不重复单独导出。
- 部分超出或完全在外的 PPP 会单独导出，避免内容丢失。

### 3.7 PicDic

- **PicDic制作**：基于 `QT/PWW/*.PWWords` 生成 GoldenDict/ABBYY DSL 图片词典及图片 ZIP，输出到 `QT/PicDic/`。必须先执行词条切图。
- **导出PicDic索引**：按全项目页面顺序输出：

```text
WORD<TAB>xx.xx<TAB>yy.yy<TAB>page
```

例如：

```text
一	0.85	19.07	0001
```

X/Y 直接使用 PDIC 已保存的比例值，不重新计算，不带百分号。

## 4. 主界面区域

### 一、普通版面参数

常用快速参数。修改后会自动应用并保存。

- **分栏数**：页面正文栏数。
- **页眉Y**：版面检测/词头候选开始的纵向位置；不是切图上边界。
- **单栏宽**：基础栏宽。
- **栏间空**：相邻栏间距。
- **单行高**：典型正文/词头行高。
- **行间空**：典型行间空白。
- **检测引擎**：检查 PaddleOCR、Tesseract、Lens 可用状态。
- **检测版面**：自动估计页面分栏结构。

### 二、基于OCR画线

- **复用缓存 / 强制重新识别**：决定是否重新跑 OCR。
- **OCR语言**：Tesseract/规则使用的词头语言代码，可组合，如 `por+chi_sim`。
- **候选带宽比例**：只分析每栏左侧多少比例的候选带；100 为 Profile 原始宽度。
- **左缘容差**：允许词头相对栏左边缘偏移的程度；越大越容易纳入正文缩进行。
- **候选置信度**：OCR 低于该置信度的候选会被弱化或过滤。
- **最低候选分**：综合版面/结构证据的最低接受分数。
- **PaddleOCR / Tesseract / Google Lens**：选择参与识别的引擎。
- **Lens模式**：控制 Lens 何时调用及是否参与最终决策。
- **Y安全空间**：横线 Y 精修后与墨迹保持的安全距离。

### 三、辅助选项及框线色块

- **栏左垂线**：显示/隐藏栏左参考线，并可选颜色、宽度。
- **词头横线**：显示/隐藏词条横线，并可选颜色、高度。
- **插图轮廓颜色 / 插图区域颜色 / 插图标签外框颜色**：只影响 PPP 显示，不修改 PPP 坐标。
- **显示候选复选框**：显示 OCR 左缘候选的人工选择框。
- **显示插图多边形**：控制 PPP 可视化。
- **切图预览（主图）**：显示最终 Crop Plan；预览与正式切图使用同一几何逻辑。
- **隐藏线框（插图除外）**：临时隐藏普通栏线/词头线，PPP 仍可显示。
- **间隔时间**：自动保存/旧版批处理相关的间隔参数。
- **自动保存**：按设定间隔保存当前编辑结果。

### 五、页面列表

列包括：

- **页面**：始终显示。
- **已画线**：PDIC 词条数量/状态。
- **填充状态**：分页词表与 PDIC 数量核对结果。
- **插图**：PPP 插图数量；0 个时留空。

点击栏头可排序。页面名使用自然排序。表头右键可关闭/重新显示“已画线”“填充状态”“插图”；“页面”不能关闭。

排序只改变列表显示顺序，不改变项目实际页面顺序或文件顺序。

## 5. Profile

Profile 是“版面识别族”，不是单纯按语言分类。内置类型：

| Profile | 适用版面 |
|---|---|
| 拉丁字母 · 音标密集双栏 | 英文粗体词头、音标/POS 密集，例如 Far East、RHWCD。 |
| 拉丁字母 · 紧邻词性经典双栏 | 葡语/意大利语经典双栏，词头紧邻 POS。 |
| 拉丁字母 · 编号词性双栏 | lemma 与 POS 中间可能有变位/索引编号，例如 XXH。 |
| 拉丁字母 · 结构符号词典型 | 学习词典/学校词典，词性、变形、条内符号较复杂。 |
| 中文 · 圆点/拼音三栏 | ○/● 等词条标记 + 中文词头 + 拼音/罗马字。 |
| 中文 · 括号词头/大字三栏 | 【】/〔〕复合词及大号单汉字词头。 |

Profile 页面可预览代表词典样页。对 Profile 参数的手工改动以项目 override 保存，不会修改程序内置预设。

## 6. 校对窗口

- 左侧为当前页词条文本框。
- 点击一个词条后，右侧显示该位置的 PaddleOCR / Tesseract / Lens 结果。
- 可一键采用某个 OCR 结果。
- 右侧 wordslist 只显示当前词附近约 501 条，适合 10 万–20 万行大型参考词表。
- **选择wordslist文件** 可更换参考词表并立即刷新。
- wordslist 中不存在的主界面词条会显示红色粗外框，存在时使用普通边框。

## 7. 大型项目与批处理

多页 OCR、填充、PDIC 备份/恢复、PicDic 索引导出、插图识别以及切图都使用后台任务或多进程策略。底部会出现：

- 当前页/总页数
- 当前文件
- 进度条
- 暂停/继续
- 停止

暂停/停止通常会在当前页完成并安全写盘后生效。已经完成的页面不会回滚。

切图的并行进程可在【切图设置】设为 `0=自动`；为避免大扫描图占用过多内存，程序会采用保守并发。

## 8. 重要安全建议

- 大批量 OCR、填充或排序前，建议先点 **备份PDIC**。
- `修复PDIC排序` 只按栏号与 Y 重排，适合“记录顺序错但词条文字仍与原坐标绑定”的 PDIC。如果文字已经配错到另一条线，必须从备份恢复或重新填词/校对。
- OCR 画线会重写所选页面 PDIC，确认页面范围后再运行。
- 自动插图识别不会覆盖人工 PPP；人工修改 AUTO 区域名称后，该区域视为人工区域。
- `切图预览（主图）` 是正式切图前最可靠的检查方式。
